# 디펙트 빌드 카드 근거: v0.111 재판정

`data/packs/v0.111.0/archetypes/defect.json`을 **v0.111.0 랭커 승리 덱만으로** 다시 판정한 기록입니다. 규칙은 [`ironclad.md` 2절](ironclad.md)과 같고, 아래만 다릅니다.

- **축 카드**: 이전 문서([`../defect.md`](../defect.md))는 축 카드 목록을 남기지 않아, 이번에는 "그 빌드의 core·enabler·payoff 카드 중 v0.111 승리 덱의 50% 이상이 드는 범용 카드를 뺀 것"으로 정했습니다(`tools/BuildSources/anchors-defect.json`). 멤버 덱 = 축 카드 2장 이상(축 카드가 2장 이하인 빌드는 1장 이상).
- **core 승격**: core 부트스트랩 80% 이상(우수, 우수가 20~80%면 전체)이고, 고급·희귀 등급이며, 효과가 빌드의 엔진(축을 공급하거나 축에 비례해 커지는 카드)일 때만 올렸습니다. 일반 등급 카드는 올리지 않았습니다.
- fullWeight·essentialTarget은 멤버 덱 정의가 이전과 달라 원칙적으로 건드리지 않았습니다(목록에서 카드를 뺀 탓에 값이 어긋난 경우만 보정).

## 1. 표본

v0.111.0 디펙트 승리 **99판·32명**(A10·일반 모드·솔로·바닐라), 우수 플레이어 **73판·16명**. 런 파일과 런 번호는 저장소에 없고 이 문서에는 합계만 있습니다.
