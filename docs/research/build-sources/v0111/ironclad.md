# 아이언클래드 빌드 카드 근거: v0.111 재판정

`data/packs/v0.111.0/archetypes/ironclad.json`을 **v0.111.0 랭커 승리 덱만으로** 다시 판정한 기록입니다.
그 전 목록은 v0.107.x와 베타(v0.108~v0.111) 런을 합쳐 정했고, 베타에서 바뀐 카드는 v0.107.x 런으로만 셌습니다([`../ironclad.md`](../ironclad.md)). 게임 기준 버전이 v0.111이 되어 그 방식이 맞지 않게 됐습니다.

## 1. 표본

- OP.GG 상위 플레이어 코퍼스(2026-11 수집, A10·일반 모드·솔로·바닐라) 중 **v0.111.0 아이언클래드 승리 192판·50명**.
- 우수 플레이어(A10 5승 이상, 1막 통과 후 승률 25% 이상): **105판·21명**. 판정은 우수 플레이어 기준, 미결이면 전체 플레이어.
- 같은 코퍼스의 v0.107.x 승리는 104판입니다(아래 3절 비교용). v2 판정 때의 683판(그중 베타 413판)보다 표본이 작습니다. 그래서 "빼기"는 아래처럼 더 조심스럽게 했습니다.
- 런 파일과 런 번호는 저장소에 넣지 않습니다. 이 문서에는 합계만 있습니다.

## 2. 규칙

[`../ironclad.md` 2절](../ironclad.md)의 v2 규칙을 그대로 씁니다: 멤버 덱 = 축 카드 2장 이상(평가하는 카드는 빼고 다시 셈), 플레이어 균형(한 사람 가중치 10% 상한), 지원 = 5명 이상·lift 1.5 이상·점유율 25% 이상(또는 15% 이상 + 10회 이상 제시 중 픽 50% 이상), core = 지원 + 엔진 후보 + 점유율 40% 이상, 플레이어 부트스트랩 200회.

v0.111 재판정에서 달라진 점은 셋입니다.

1. **버전**: v0.111.0 런만 씁니다. 모든 카드를 같은 런으로 셉니다(베타 변경 카드 예외 없음).
2. **축 카드 갱신**: v0.111에서 효과가 바뀐 카드를 반영했습니다.
   - 힘 성장에 `EXPECT_A_FIGHT` 추가: "공격 카드 수만큼 에너지"에서 "방어도 + 힘 1당 추가 방어도"로 바뀜.
   - 소멸에서 `FORGOTTEN_RITUAL` 제외: 소멸 조건이 사라져 어느 덱에서나 쓰는 에너지 카드가 됨(v0.111 승리 덱 보유 48%).
   - 자해에 `CRIMSON_MANTLE` 추가: 매 턴 체력 1을 잃는 파워(v2에서 이미 자해 core 후보였음).
3. **넣기와 빼기**:
   - 넣기 = 지원 부트스트랩 80% 이상(우수, 우수가 20~80%면 전체) **그리고** 카드 효과가 빌드 축에 작용.
   - 빼기 = 우수 멤버 덱 25판 이상인 빌드에서, 지원 부트스트랩이 우수·전체 모두 20% 이하이고 lift 1.0 이상인 재표본도 80% 미만일 때만.
   - 그 밖은 표본이 작아 결정하지 않고 이전 역할을 둡니다.

다시 만드는 법은 [`tools/BuildSources/README.md`](../../../../tools/BuildSources/README.md)에 있습니다.

## 3. 버전 사이에 달라진 것

승리 덱 중 각 빌드 멤버 덱의 비율(같은 코퍼스, 같은 축 카드, 원시 비율, 한 덱이 여러 빌드에 속할 수 있음):

| 빌드 | v0.107.x (104판) | v0.111.0 (192판) |
|---|---|---|
| 힘 성장 (EXPECT_A_FIGHT 제외한 옛 축) | 36% | 23% |
| 소멸 | 33% | 55% |
| 방어 누적 | 13% | 23% |
| 자해 (옛 축) | 20% | 14% |
| 취약 | 49% | 52% |
| 공격 재사용 | 19% | 22% |
| 타격 템포 | 33% | 15% |
| 타격 자동 사용 | 15% | 9% |

v0.111에서는 소멸과 방어 누적이 늘고 타격 템포·타격 자동 사용·힘 성장이 줄었습니다.

| 빌드 | core | 바뀐 것 |
|---|---|---|
| 힘 성장 | 없음 | + `EXPECT_A_FIGHT`(payoff), + `FIGHT_ME`(enabler), − `BLOOD_WALL`(support), onTheme − `RUPTURE` |
| 소멸 | FEEL_NO_PAIN | + `HOWL_FROM_BEYOND`(payoff), essentialTarget 2 → 3 |
| 방어 누적 | BARRICADE | 없음 |
| 자해 | RUPTURE | 없음(우수 멤버 덱 19판이라 빼기 판정 안 함) |
| 취약 | 없음 | 없음 |
| 공격 재사용 | 없음 | + `UNRELENTING`(enabler), + `BLUDGEON`(support), 둘 다 onTheme에서 올림 |
| 타격 템포 | 없음 | 없음(우수 멤버 덱 18판) |
| 타격 자동 사용 | HELLRAISER | 없음 |

**core는 그대로 4장입니다.** v0.111 표본에서 core 기준(엔진 후보·점유율 40% 이상·부트스트랩 80% 이상)을 새로 넘은 카드가 없습니다. 가장 가까운 카드:

- 힘 성장 `FIGHT_ME`: 우수 점유율 45%, core 부트스트랩 우수 74%·전체 23%.
- 힘 성장 `EXPECT_A_FIGHT`: 점유율 56%, 부트스트랩 80%·70%. 하지만 힘이 있어야 값이 나오는 카드라 엔진이 아닙니다. core로 두면 "코어 먼저" 규칙이 힘 공급원보다 이 카드를 먼저 밀게 됩니다.
- 방어 누적 `BARRICADE`(core 부트 56%·65%), 자해 `RUPTURE`(32%·40%)는 미결이라 이전 판정(core)을 유지했습니다.

기준을 넘었지만 넣지 않은 카드(효과가 빌드 축에 작용하지 않음): 힘 성장 `CRIMSON_MANTLE`(전체 부트 89%), 취약 `FLAME_BARRIER`(전체 84%), 타격 템포 `MAD_SCIENCE`(전체 82%).

fullWeight는 새 목록으로 우수 멤버 덱 commit 중앙값을 다시 쟀고 모두 보정 조건 밖이라 그대로입니다(힘 0.80, 소멸 0.84, 방어 0.96, 자해 0.91, 취약 0.84, 공격 재사용 0.85, 타격 자동 사용 0.76). 타격 템포만 0.57로 0.7 아래지만 멤버 덱 18판이라 바꾸지 않았습니다.
