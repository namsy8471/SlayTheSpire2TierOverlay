# 네크로바인더 콤보 확인 (combos_check)

**결론부터: 이 작업 공간의 읽기 전용 저장소 사본에는 `data/packs/v0.107.1/combos/`에 `ironclad.json`만 있고 `necrobinder.json`이 없습니다.** GitHub 저장소도 이 세션에서는 열 수 없었습니다. 그래서 네크로바인더 콤보 항목을 하나씩 검사하지는 못했습니다. 콤보 파일은 고치지 않았습니다.

대신 (1) 콤보 파일이 있으면 바로 돌릴 수 있는 검사 스크립트와 (2) 아키타입 카드끼리의 모든 쌍(218쌍)에 대한 동시 출현 lift 표를 남깁니다. 콤보 쌍이 두 카드 모두 아키타입 목록에 있으면 아래 표에서 찾으면 됩니다.

## 방법

- 표본: 네크로바인더 A10 바닐라 승리 덱, 좋은 플레이어 317판·14명(전체 381판·38명 값도 계산). 베타 변경 카드가 낀 쌍은 v0.107.x 런만.
- lift = P(A와 B 함께) ÷ (P(A) × P(B)), 각 확률은 플레이어 균형값(한 사람 최대 10%).
- 지지 = lift ≥ 1.2 이고 두 카드를 함께 든 플레이어 ≥ 5명. 플레이어 200회 재표본에서 80% 이상 지지면 OK, 20% 이하면 **미지지**, 그 사이는 불확실.
- 검사 스크립트(통합 담당자용, 스크래치): `python3 -I <scratch>/v2/arch-necrobinder/_work/combos_check.py <저장소>/data/packs/v0.107.1/combos/necrobinder.json` → 콤보마다 OK / NOT SUPPORTED / UNCERTAIN 출력.
