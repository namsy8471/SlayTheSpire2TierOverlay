# v2 가중치 측정 (경로·휴식·상점·스킵·덱 크기)

> **레포에 반영한 값은 `idealDeckSize`(21/27/31)와 `path.targetElites`(2/2/2)뿐입니다.** 아래 표의 나머지 "변경" 제안(방별 HP 손실·골드 등)은 상위 플레이어의 A10 솔로 값이라, 승천 0~4·주로 2인 협동인 실제 사용 환경에서 잰 지금 값을 그대로 두고 참고로만 남겼습니다.

상위 플레이어 A10 기록에서 잰 통계입니다. 좋은 플레이어 22명의 승리 1686판과 실제 패배 1650판(포기 제외), 그리고 전체 100명의 승리 2731판을 썼습니다. 판정은 **좋은 플레이어 + 플레이어 균형(1인 가중치 상한 10%) + 부트스트랩 80%** 기준입니다.

- 비율·평균은 각 플레이어의 값을 표본 수로 가중하되 한 사람이 전체의 10%를 넘지 못하게 한 값(균형값)입니다. 표의 "좋은(전체)"는 좋은 플레이어 값(괄호: 전체 플레이어 값)이고, 균형 없는 원값은 measured.json의 `raw`에 있습니다.
- 부트스트랩: 플레이어를 복원 추출해 200번 다시 계산합니다. 제안값은 재표본의 80% 이상이 그 값의 ±10% 안에 있어야 "유지"입니다(엘리트 수는 같은 정수여야 함).
- 승리와 패배 비교는 양쪽 모두 좋은 플레이어만 씁니다. 패배 쪽 경로 통계는 끝까지 마친 막만 셉니다.
- `?` 방 분류: 방 ID가 전투 ID면 전투, 빈 ID에 카드·포션 목록이 있거나 유물 후보가 2개 이상이면 상점, 그 밖의 빈 ID는 보물 상자, 나머지는 이벤트(card_stats.py와 같은 규칙).
- 덱 크기는 최종 덱에서 거꾸로 획득·제거·변환을 되돌려 층마다 복원했습니다(모든 런에서 시작 덱과 일치).
