# 경로 추천: 쉬운/어려운 일반 전투 풀 (2026-11)

사용자 제보: 경로 추천이 일반 전투를 5번 이상 연속으로 고르는 길을 자주 권함.

## 게임 규칙 (디컴파일, v0.107.1)

- `ActModel.GenerateRooms`: 막마다 일반 전투 목록을 미리 만든다. 앞쪽 `NumberOfWeakEncounters`개는 쉬운 풀(`IsWeak`, id가 `_WEAK`로 끝남), 나머지는 어려운 풀.
  - Overgrowth / Underdocks(1막) 3개, Hive(2막) / Glory(3막) 2개.
- `RoomSet.NextNormalEncounter = normalEncounters[normalEncountersVisited]`. 몬스터 방과, 전투가 나온 "?" 방(`RunManager.CreateRoom → PullNextEncounter`)이 모두 다음 전투를 하나 꺼낸다. 이벤트가 직접 여는 전투는 꺼내지 않는다.
- 세이브 `acts[cur].rooms`에 `normal_encounter_ids`와 `normal_encounters_visited`가 있다. 방 입장 세이브는 전투를 꺼내기 **전에** 쓰인다(SaveRun → CreateRoom → AppendToMapPointHistory).
- 검증: 랭커 2,155런에서 "막의 n번째 일반 전투가 쉬운 풀인가"가 규칙과 99.1% 일치(23,428 / 23,651, 어긋난 0.9%는 이벤트 전투 등).

## 측정

`tools/PathStats`에 `monster_easy` / `monster_hard` 행을 추가했다 (`PathFloor.EasyPool`, 기존과 같은 k = 8 축소).

| 막 | 쉬운 풀 (내 런 50개) | 어려운 풀 (내 런) | 랭커 A10 쉬운 / 어려운 (참고) |
|---|---|---|---|
| 1 | 5.0% (n 197) → 0.051 | 12.5% (n 135) → 0.122 | 5.8% / 10.3% |
| 2 | 14.1% (n 83) → 0.137 | 16.4% (n 80) → 0.158 | 8.8% / 11.6% |
| 3 | 13.7% (n 46) → 0.134 | 14.4% (n 30) → 0.138 | 8.0% / 9.7% |

- "?" 방이 전투가 될 확률: 랭커 18.9% (n 15,021), 내 런 15.2% → `UnknownFightChance` 0.18.
- 카드 보상 픽률(아무 카드나 가져감)은 막 안에서 보상을 받을수록 떨어진다. 랭커 1막 0.97 → 0.92 → 0.90 → 0.86 → 0.83 → 0.80 (보상당 첫 보상의 −3.4%), 2막 −3.5%, 3막 −1.8% → `CardRewardDecay`, 하한 `CardRewardFloor` 0.5.

## 모델

`PathScorer`가 경로를 걸으면서 이번 막의 일반 전투 순번을 센다(시작값: 세이브의 `normal_encounters_visited`, 없으면 지나온 몬스터 방 수). 몬스터 방은 순번이 쉬운 풀 안이면 쉬운 손실, 넘으면 어려운 손실. "?" 방은 순번을 0.18만큼 올린다(기대값). 카드 보상은 이번 막에서 앞서 받은 보상(일반 + 엘리트) 수만큼 줄어든다.

## 실제 지도 15장으로 확인 (막 시작, HP 100% / 80% / 60%)

사용자 세이브 스냅샷에서 모은 서로 다른 막 지도 15장(1막 6, 2막 7, 3막 2).

| | 1막 일반 전투 수 | 1막 최장 연속 | 연속 ≥ 4인 1·2막 지도 (13장) | 1막 엘리트 |
|---|---|---|---|---|
| 이전 | 5.7 – 6.0 | 5 | 최대 2 | 0.7 – 1.7 |
| 이후 | 4.3 – 4.5 | 3 | 0 | 0.5 – 1.5 |
| 랭커 실제 | 4.5 | (가장 흔한 값 2) | 1막의 8.4% | 2.06 |

3막 지도 1장은 모든 길이 일반 전투 4연속으로 시작해서(지도에 강제됨) 제외하고 셌다.

엘리트·휴식처·상점·"?" 점수값([추정])은 그대로 두었다. HP 손실 표만 랭커 값으로 바꾸면 같은 지도에서 1막 구성이 일반 4.5 / "?" 3.5 / 엘리트 2.17 / 휴식 2.83 / 상점 1.0으로 랭커(4.5 / 3.1 / 2.06 / 2.89 / 0.8)와 거의 같다. 즉 보상 점수는 이미 상위권 플레이 구조를 재현하고, 사용자에게 엘리트를 덜 권하는 이유는 사용자 런의 엘리트 피해(1막 28.5%, 랭커 23%)와 사망률이 더 높기 때문이다. `UnknownReward` 5 / 6 / 7, `EliteReward` 22 / 26 스윕은 지도 6 – 7장 수준의 잡음 안에서만 달랐다.
